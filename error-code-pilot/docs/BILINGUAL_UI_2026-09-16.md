# 中英文界面切换 — 2026-09-16

依据用户在010完成后的直接要求：主管需要中文界面，英文界面只显示英文。本次为显示层更新，不新增维修知识或改变Task010的诊断边界。

## 使用方式

打开本机 `http://127.0.0.1:8796`，右上角点击 **Switch to Chinese** 进入中文；点击 **切换为英文** 返回英文。原页面已打开时刷新一次即可加载新版本。

默认英文。当前标签页记住语言偏好；刷新仍清空故障选择和维修结果。切换语言本身保留机型、症状、输入内容、当前结果、已展开说明、验证勾选及处理结果。仅记录语言偏好，不保存工单信息。

英文模式不显示中文系统文案，语言按钮也使用英文。中文覆盖首页、受控选项、条件确认、维修步骤、折叠详情、安全提示、验证、PIE转交、错误提示和结果反馈。型号、错误码、固件版本、品牌及必要工具名称保持准确；代理自己输入的补充描述原样显示，不自动翻译或用于判断换件。

## 实现边界

- 300条界面/运行提示/指导文本翻译，其中公开知识所需的196条均有中文。构建时检查公开指导完整性，新增文案缺少中文则阻止覆盖最后有效构建。
- 翻译仅作用于显示文本与无障碍标签；受控ID、搜索、路径选择、动作绑定、固件匹配和处理结果仍使用原始数据。不会将中文显示文案送入维修判断。
- canonical知识、engine及service-plan未改变；1202、PIE_ONLY、Other及换件限制保持。
- 启动服务和独立运行资源白名单已包含语言模块。语言切换不依赖外部翻译服务，没有新增网络请求。
- 本机8796旧实例经六个页面文件逐字节匹配及进程/端口核对后重启；新实例的完整构建标识及语言模块响应已验证。未操作MAIN或8787。
